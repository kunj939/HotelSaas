# Image and licensing notes

The **500 bundled SVG images are original generated menu illustrations, not photographs**, so do not present them to customers as photos of a real dish. `photo_verified: false` is intentional. They may be used as restaurant placeholders.

For photographic images, restaurant owners can upload their own photographs, or use the Wikimedia Commons suggestions in the Menu editor. Wikimedia image results include the creator, licence and original file page. Inspect relevance, attribution and licence requirements before publishing. Some photos may be unavailable.

The 500-item JSON file is a name autocomplete starter catalog. It is NOT 500 photo assets. Public domain/CC licensing cannot be assumed from a web image search.
